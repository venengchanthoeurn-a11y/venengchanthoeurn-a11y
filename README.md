### 📚 KDLMS — បណ្ណាល័យឌីជីថលខ្មែរ
> **Khmer Digital Library Management System**
*   **ការពិពណ៌នា៖** ប្រព័ន្ធគ្រប់គ្រងបណ្ណាល័យឌីជីថលលំដាប់ Full-Stack (PHP/MySQL) បង្កើតឡើងជាប្រភេទ PWA (Progressive Web App) ដែលអាចដំណើរការក្រៅបណ្តាញ និងដំឡើងលើទូរស័ព្ទដៃបាន។
*   **មុខងារសំខាន់ៗ៖**
    *   🔍 **AJAX Search:** ស្វែងរកសៀវភៅ ឬឯកសារភ្លាមៗដោយមិនបាច់ Reload ទំព័រ
    *   📖 **Multi-format Support:** គាំទ្រឯកសារ PDF, DOCX, EPUB និង MP4
    *   🔐 **Role Access Control:** បែងចែកគណនី Superadmin, Admin និងអ្នកអាន
    *   📊 **Admin Dashboard:** ស្ថិតិការទាញយកឯកសារ និងចំនួនអ្នកអានច្បាស់លាស់
*   **បច្ចេកវិទ្យា៖** PHP 8.2, PDO, MySQL, Bootstrap 5.3, Service Worker, Chart.js
*   [🔗 មើលកូដនៅក្នុង GitHub Repository](https://github.com/venengchanthoeurn-a11y/KDLMS)

### 📅 momentkh (បណ្ណាល័យប្រតិទិនចន្ទគតិខ្មែរ)
> **Khmer Lunar Calendar utility for JavaScript**
*   **ការពិពណ៌នា៖** បណ្ណាល័យកូដបន្ថែម (Add-on) លើ Moment.js ពេញនិយម ដើម្បីបំប្លែងកាលបរិច្ឆេទគ្រិស្តសករាជទៅជាថ្ងៃខែឆ្នាំចន្ទគតិខ្មែរ និងគណនាម៉ោងទេវតាចុះក្នុងឱកាសបុណ្យចូលឆ្នាំថ្មីប្រពៃណីជាតិ។
*   **មុខងារសំខាន់ៗ៖**
    *   🌙 **បំប្លែងចន្ទគតិ:** បង្ហាញជាទម្រង់ខ្មែរពេញលេញ (ឧ. ថ្ងៃសៅរ៍ ៨កើត ខែមិគសិរ ឆ្នាំច សំរឹទ្ធស័ក)
    *   🎉 **ម៉ោងទេវតាចុះ:** គណនាពេលវេលាទេវតាចុះឆ្នាំថ្មីតាមក្បួនគណនាសូរិយាត្រាខ្មែរបុរាណ
    *   ⚙️ **Custom Format:** អាចកំណត់ទម្រង់បង្ហាញកាលបរិច្ឆេទដោយខ្លួនឯងបានច្រើនទម្រង់ (W, d, m, a, b...)
